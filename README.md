# neutrino-transition-moments
Dynamic fermion flavor mixing through transition dipole moments

## abstract
In this paper, we show that Majorana neutrino flavor mixing can be driven by transition dipole moments in the presence of external electromagnetic fields. We demonstrate the sensitivity of the rotation mixing matrix to strong fields obtaining dynamical mass eigenstates in the two-flavor model. The three-flavor case, and extensions to the quark sector, is introduced.
